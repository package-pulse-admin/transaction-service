# transaction-service

## Overview

The Transaction Service is responsible for processing customer order events and creating financial transaction records. 
It consumes Change Data Capture (CDC) events produced by Debezium, applies business rules such as fee calculation, 
stores the processed transaction, and publishes follow-up events for downstream services.

## Architecture

Customer Orders (MySQL) -> Debezium CDC -> Kafka -> Transaction Service -> Payment Service

## Features
- Consumes Kafka events generated by Debezium
- Processes only newly created customer orders
- Maps Debezium payloads to domain DTOs
- Calculates transaction fees
- Calculates the total transaction amount
- Persists transactions in MySQL
- Publishes transaction events for downstream microservices
- Exposes health and Prometheus metrics

## Configuration

The application uses environment variables.

| Variable | Description |
|-----------|-------------|
| DB_HOST | MySQL host |
| DB_PORT | MySQL port |
| DB_USERNAME | Database username |
| DB_PASSWORD | Database password |
| KAFKA_BOOTSTRAP_SERVERS | Kafka broker |

## Database

| Column       | Description            |
| ------------ | ---------------------- |
| id           | Transaction identifier |
| customer_id  | Customer identifier    |
| order_id     | Associated order       |
| amount       | Original order amount  |
| currency     | Transaction currency   |
| status       | Transaction status     |
| total_amount | Amount including fees  |
| created_at   | Creation timestamp     |
| updated_at   | Last update timestamp  |

## Kafka

Consumes 'order-platform.order_platform.customer_orders'
Produces 'order-platform.customer_transactions'

## Fee Calculation

The service calculates transaction fees using dedicated fee calculation strategies.
Every applicable fee is stored separately and contributes to the final transaction total.

## Event Flow

1. Order Service saves data in MySQL.
2. Debezium detects INSERT, UPDATE and DELETE operations.
3. Debezium publishes events to Kafka.
4. Transaction Service consumes the events.
